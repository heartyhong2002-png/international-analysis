## 1. 프로젝트 개요

**국제정세 분석 (International Affairs Analysis)**

## 4. 분석 방법론

### 4.1 데이터 수집 방법

**1차 데이터 (Primary)**
- 공식 통계 및 정부 발표
- 국제기구 보고서 (UN, IMF, World Bank, WTO)
- 언론 보도 및 뉴스 모니터링

**2차 데이터 (Secondary)**
- 학술 논문 및 연구 보고서
- 싱크탱크 분석 자료
- 역사적 데이터 기록

### 4.2 지표 산출 방법

**정량 분석**
```
단순 지표 = 해당 수치의 시계열 데이터
복합 지표 = (Σ 개별 지표 × 가중치) / 100
```

**정성 분석**
- 사건의 국제적 영향도 평가
- 전문가 판단 및 평가
- 뉘앙스 및 맥락 분석

### 4.3 차트 생성 방식

**Line Chart**: 시간에 따른 추이 분석
**Bar Chart**: 지역/국가별 비교
**Heatmap**: 시간대별 강도 표시
**Pie Chart**: 구성비 분석
