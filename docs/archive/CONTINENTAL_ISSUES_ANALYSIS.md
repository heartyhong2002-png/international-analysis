## 📊 분석 프레임워크

각 이슈별로 다음 지표를 추적:

1. **정량 지표** (FRED, GDELT, UN Comtrade)
   - 경제 지표: 환율, 무역량, 금리, 주가
   - 뉴스 감정도: 기사 수, 톤 분석
   - 제재 현황: OpenSanctions

2. **정성 지표**
   - 정책 성명 & 외교 활동
   - 국제 여론
   - 주요 사건 타임라인

3. **위험도 평가**
   - 이슈 강도 (0-100)
   - 우려 수준 (🟢 낮음 / 🟡 중간 / 🔴 높음)
