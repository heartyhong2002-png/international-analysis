# 보류 — 챗봇 서비스 전환

**보류일:** 2026-09-20
**사유:** 같은 날 프로젝트 정체성을 재정리하면서(문서감사 2026-09-18 후속 논의),
준기님이 목적=교과목/졸업 과제물, 최종 결과물=종합 대시보드(HTML)로 확정함.
이 폴더의 챗봇 전환 제안은 그 결정과 방향이 달라서(대시보드를 "정적이라 부족하다"고
전제하는 문서였음) 보류하기로 함.

**삭제하지 않은 이유:** `chatbot_core/`(FastAPI 백엔드, 의도분류·데이터검색·응답생성)와
`frontend/index.html`까지 이미 상당 부분 만들어져 있었고, `README.md`(Phase 1 v2
인수인계 문서)와 `로컬_채팅_테스트_점검표.md`도 있어서 나중에 방향을 다시 바꿀 경우
바로 이어받을 수 있게 남겨둠.

**여기 있는 것:**
- `chatbot_core/` — FastAPI 백엔드 프로토타입
- `frontend/` — 최소 HTML 프론트엔드
- `chatbot_prototype.zip`, `chatbot_prototype_v2.zip`
- `README.md` — 이 프로토타입 자체의 인수인계 문서 (Phase 1, v2)
- `로컬_채팅_테스트_점검표.md` — 로컬 테스트 체크리스트

**원본 제안 문서:** Claude 프로젝트 문서함의 `챗봇_서비스_전환_전략.md`,
`챗봇_구현_세부_계획.md`에 전체 설계 논의가 남아있음 (이 프로젝트에는 파일로 없음).

**재검토하려면:** 이 폴더를 루트로 다시 옮기고, `project-handoff.md`에 재개 사유를
한 줄 남긴 뒤 시작하면 됨.
