# 조기경보 데이터 수집 가이드

## 1. 수집 원칙

조기경보 시스템의 데이터는 미래 사건을 맞히기 위한 정답지가 아니라, 위험 신호를 관측하기 위한 센서다. 하나의 출처만으로 경보를 만들지 않고, 공식 신호, 독립 신호, 대중 신호, 시장 신호를 분리해서 수집한 뒤 서로의 차이를 비교한다.

## 2. 데이터 유형

| 데이터 유형 | 역할 | 대표 파일·스크립트 |
|---|---|---|
| 뉴스 RSS | 이슈별 보도량과 논조 변화 탐지 | `prototype_all_in_one.py`, `data/review_log.csv` |
| 정부 공식 발표 | 공식 입장과 정책 신호 확인 | `scripts/gov_announcements_collector.py` |
| 현지 독립 언론 | 통제 국가의 공식 발표와 다른 신호 확인 | `scripts/fetch_signal_gap_rss.py` |
| Reddit·커뮤니티 | 보조 정성 신호와 현지 체감 반응 확인 | `scripts/fetch_reddit_opinion.py`, `scripts/parse_local_reddit.py` |
| 여론조사 | 중기 여론 압력과 정책 지지 변화 확인 | `scripts/fetch_polling_data.py` |
| 금융 프록시 | 시장이 반응하는 공급망·자본 이동 신호 확인 | `scripts/fetch_financial_proxy.py` |
| 무역·관세·거시지표 | 공급망 리스크의 실물 지표 확인 | `scripts/fetch_customs_korea_china.py`, `scripts/fetch_us_macro_signals.py` |
| 텔레그램 OSINT | 공개 채널 기반 현장성 있는 위험 징후 확인 | `scripts/fetch_telegram_public.py` |

## 3. 조기경보 판단에 쓰는 방식

각 데이터는 다음 질문에 답하기 위해 사용한다.

- 공식 발표는 안정적이라고 말하는가, 긴장을 인정하는가?
- 독립 언론이나 현지 커뮤니티는 같은 이슈를 다르게 보고 있는가?
- 보도량과 비판적 논조가 최근 며칠 사이 증가했는가?
- 금융·무역 지표가 텍스트 신호와 같은 방향으로 움직이는가?
- 경보를 낼 만큼 근거 출처가 충분한가?

## 4. 데이터 재사용 판단

기존 수집 데이터는 새 방향과 충돌하지 않는다. 예측 접근에서는 이 데이터가 미래 사건을 맞히기 위한 입력이었다면, 조기경보 접근에서는 위험 신호를 관측하고 설명하기 위한 근거가 된다.

다만 레딧과 커뮤니티 데이터는 노이즈가 크므로 주 지표가 아니라 보조 정성 지표로 둔다. 수동 CSV는 핵심 자동 파이프라인이 아니라 MVP 검증용 기준 데이터나 예시 데이터로 사용한다.

## 5. 수집 우선순위

1. 정부 발표와 뉴스 RSS
2. 현지 독립 언론과 신호 괴리율 RSS
3. 금융·무역 프록시
4. 여론조사와 Reddit 보조 신호
5. 텔레그램 OSINT와 기타 공개 데이터셋

## 6. 경보용 데이터 품질 기준

- 출처 URL 또는 파일 경로가 남아 있어야 한다.
- 수집 일시가 있어야 한다.
- 이슈 ID와 연결되어야 한다.
- LLM이 판단한 경우 근거 문장 또는 판단 이유가 있어야 한다.
- 사람이 검수한 경우 검수 결과와 수정 사유가 남아야 한다.

## 7. 국가별 정보환경과 수집 우선순위

국가의 지역이나 체제 명칭만으로 같은 수집 규칙을 적용하지 않는다. 지역은 언어·시간대·공통 이슈를 묶는 운영 단위이며, 실제 수집·해석은 국가별 정보환경 프로필을 따른다.

정보환경은 `자유로움`, `비교적 자유로움`, `비교적 폐쇄적임`, `폐쇄적임`의 네 단계로 관리한다. 이 등급은 국가의 진실성이나 국민의 의견을 평가하는 것이 아니라, 공개 자료를 독립적으로 검증할 수 있는 정도를 나타낸다.

- 자유롭거나 비교적 자유로운 환경: 현지 독립 언론, 방법론이 공개된 여론조사, 공식 발표, 공개 SNS를 교차 확인한다.
- 비교적 폐쇄적인 환경: 공식·국영 서사와 독립·망명·제3국 자료를 분리하고, 출처 간 서사 차이를 위험 신호로 본다.
- 폐쇄적인 환경: 현지 공개 여론을 추정하지 않는다. 제3국 무역·통관, 해운·항공·위성, 국제기구, 공식 서사 변화와 정보 공백을 중심으로 관측한다.

모든 국가에는 아래 두 축을 별도로 기록한다.

| 축 | 질문 | 수집·경보에 미치는 영향 |
|---|---|---|
| 정보 관측 가능성 | 특정 이슈를 공개·독립·재현 가능한 근거로 얼마나 확인할 수 있는가? | 확인 수준과 불확실성 문구를 결정한다. |
| 한국 공급망 영향도 | 사건이 한국 제조업·무역·물류·에너지에 미칠 잠재 충격은 어느 정도인가? | 수집 빈도와 우선 검토 대상을 결정한다. |

기술 자립도·기술 의존도는 정보환경 등급이 아니라 공급망 영향도 판단 요소다. 핵심 부품·원자재, 에너지·해상 물류, 수출시장·현지 생산거점, 제재·수출통제, 무역 데이터의 시차를 함께 본다.

따라서 `정보 관측 가능성 낮음 + 공급망 영향도 높음`인 국가는 사건을 단정하는 대신 외부 행동지표를 고빈도로 수집하고, 결과에 `low_observability`와 근거 범위를 함께 표시한다.

국가별 시범 프로필과 상세 운영 규칙은 [정보환경 프로필 v1](INFORMATION_ENVIRONMENT_PROFILE_V1.md)을 따른다.
