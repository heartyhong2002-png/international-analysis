# 보류된 접근 챗봇 서비스 전환

## 검토한 이유

대시보드가 정적 결과물처럼 보일 수 있다는 우려 때문에, 사용자가 국제정세 데이터에 대해 질문하고 답변을 받는 챗봇 서비스 전환을 검토했다. 이 방향은 사용성 면에서 매력적이고, 최종 결과물이 "서비스"처럼 보인다는 장점이 있었다.

## 어느 정도까지 실행했는가

챗봇 관련 프로토타입과 점검 문서는 `docs/archive/parked_chatbot_pivot/`에 보존했다. FastAPI 기반 백엔드와 프론트엔드 방향을 검토했고, 로컬 LLM을 챗봇 응답에 연결하는 테스트 흐름도 일부 정리했다.

## 보류한 이유

챗봇은 사용자 경험을 개선할 수 있지만, 현재 졸업작품의 핵심 문제인 데이터 수집, 신호 탐지, LLM 판단 검증, 경보 근거 추적을 흐릴 위험이 있었다. 또한 챗봇 응답 품질을 검증하려면 별도의 평가 기준이 필요해져, 예측 접근과는 다른 방식으로 검증 부담이 커질 수 있었다.

## 현재 판단

챗봇은 삭제하지 않고 향후 확장 기능으로 보류한다. 현재 졸업작품의 최종 결과물은 조기경보 대시보드이며, 챗봇은 대시보드와 리포트가 안정화된 뒤 붙일 수 있는 질의응답 인터페이스로 남긴다.
