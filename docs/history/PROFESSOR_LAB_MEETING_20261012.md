# 교수님 연구실 면담 기록 2026년 10월 12일

## 기록 목적

개인 프로젝트를 지도교수님께 설명한 뒤 제안받은 학부연구생·연구실 참여 가능성을 기록한다. 이 기록은 참여를 확정한 문서가 아니라, 연구실 환경과 역할을 판단하기 위한 면담 메모다.

## 면담에서 확인한 방향

- 교수님 연구실 프로젝트는 국제정세 조기경보 프로젝트와 동일한 주제가 아닐 수 있다.
- 이번 미팅의 주된 목적은 석사생들이 연구 주제를 정하고 교수님에게 컨펌받는 과정을 옆에서 관찰하며 연구실의 프로젝트 진행 방식을 판단해보는 것이었다.
- 데이터 플랫폼, 비정형 데이터 처리, 분석 인프라, 시스템·아키텍처 설계, 데이터 파이프라인, 개발·기획·요구사항 분석 역량이 중요하게 언급되었다.
- Python과 데이터 분석 역량을 계속 보강할 필요가 있다.
- 금융·대외경제·사회과학·정책연구와 연결되는 연구 주제와 정부과제 가능성이 언급되었다.
- 학부연구생 참여, TIPI LAB 관련 활동, 학·석사 연계·조기졸업 가능성은 구체적인 조건을 추가 확인해야 한다.
- 개인 프로젝트의 데이터를 연구실 프로젝트나 사이드 프로젝트에 활용할 가능성이 언급되었으나, 자료 소유권·공개 범위·연구윤리는 별도 확인이 필요하다.

## 현재 결정 상태

현재는 **참여 확정이 아니라 검토 중**이다. 교수님이 요청한 답변 시점까지 연구실의 역할, 주당 시간, 활동 기간, 지도 방식, 연구 성과 인정 방식, 개인 프로젝트와의 병행 가능성을 확인한 뒤 결정한다.

이 제안은 개인 프로젝트를 연구실 프로젝트로 흡수한다는 의미가 아니다. 개인 프로젝트는 계속 개인 포트폴리오로 관리하고, 연구실 참여는 별도의 학습·연구 경험으로 판단한다.

## 판단 기준

1. 학부연구생이 실제로 맡게 되는 업무가 명확한가
2. 데이터 처리·분석·시스템 설계 역량을 배울 수 있는가
3. 주당 시간과 활동 기간이 현재 수업·개인 프로젝트와 양립 가능한가
4. 초보자로서 질문하고 피드백받을 수 있는 연구실 분위기인가
5. 결과물·논문·발표·포트폴리오 활용 조건이 명확한가
6. AI 도구 사용과 데이터·코드·결과물의 소유권 규정이 명확한가

## 다음 확인 사항

- 구체적인 역할과 첫 과업
- 주당 예상 활동 시간과 최소 참여 기간
- 담당 석사생 또는 멘토 유무
- 연구실 프로젝트와 개인 프로젝트의 분리·병행 기준
- 데이터 접근 권한과 공개·재사용 조건
- 학부연구생 성과 인정 방식과 지원 조건

## 기록 원칙

이 면담은 개인 프로젝트의 방향을 국제정세 예측이나 연구실 프로젝트로 변경한 사건이 아니다. 현재 프로젝트는 계속 OSINT 기반 공급망·지정학 리스크 조기경보 포트폴리오로 유지한다.
