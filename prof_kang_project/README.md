## 💡 AI 세션 활용 방법

1. **교수님 미팅 직후**:
   - 대화창에 미팅 메모나 녹음 요약, 말씀하신 내용을 편하게 붙여넣으시면 `feedbacks/YYYYMMDD_feedback.md` 파일로 구조화하여 정리하고 To-Do를 업데이트합니다.
2. **진행보고서 작성 시**:
   - 최근 작업 내용(데이터 분석 결과, 파이프라인 상태 등)을 바탕으로 교수님 보고에 적합한 정중하고 명확한 주간/격주 보고서를 즉시 생성합니다.
3. **발표 PPT 준비 시**:
   - 슬라이드별 핵심 헤드라인, 3단 불렛포인트, 시각화 아이디어, 발표 대본(스크립트)까지 한 번에 기획해 드립니다.
4. **논문 작성 시**:
   - 서론의 Research Gap 도출부터 선행연구 표, 가설 검증 결과 해석, 경영학적 시사점 도출까지 학술 문체로 작성을 보조합니다.
