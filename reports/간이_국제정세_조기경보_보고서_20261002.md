# 간이 국제정세 조기경보 보고서

**기준 시각:** 2026-10-02  
**분석 범위:** 홍해·바브엘만데브 및 호르무즈 해협 중심 공급망 위험  
**문서 성격:** 수집 신호 기반 검토용 보고서

## 1. 핵심 요약

홍해·바브엘만데브와 호르무즈 해협에서 해상 운송과 에너지 공급망에 영향을 줄 수 있는 위험 신호가 동시에 관측됐다. GDELT Cloud 사건 후보, 해협 프로필, 해운시장 지표, 공개 온라인 정보환경 신호가 같은 기간에 결합된 사례가 확인되어 **조기경보 후보는 Warning 검토 대상**으로 분류한다.

다만 현재 GDELT 수집은 1페이지 제한 프로브(`complete=false`)이고, 일부 사건은 공개 주장·시장 프록시·해협 프로필에 의존한다. 따라서 이 보고서는 실제 공격, 해협 봉쇄 또는 공급 중단을 확정하지 않으며, 정식 Alert Level은 `v_dashboard_current_alerts`와 연결된 근거·검증 상태 확인 후 확정해야 한다.

## 2. 주요 관측 신호

### 홍해·바브엘만데브

- 해협 프로필은 희망봉 우회 시 운송 지연이 약 10~14일 추가될 수 있고, 전쟁위험보험료가 높은 수준으로 나타난다.
- 컨테이너 선사 ZIM의 월간 변동은 +6.17%로 기록됐으나, 단일 시장 지표만으로 실제 물동량 변화를 확정할 수 없다.
- 예멘·홍해 해상안보 관련 GDELT 사건 후보가 2026-09-26~2026-10-01 사이에 여러 건 관측됐다.
- 유럽연합의 Aspides 해상 임무 보강 관련 사건 후보는 상선 보호 수요와 해상안보 부담이 지속되고 있음을 시사하지만, 원문 추가 확인이 필요하다.

### 호르무즈 해협·이란 주변

- 2026-10-02 GDELT 사건 후보에는 미국의 중동 병력·항모 전개 관련 보도가 포함됐다. 사건 요약 자체도 구체적인 전개 위치와 발생 시점을 완전히 확정하지 못한다고 기록한다.
- 원유탱커 선사 FRO는 일간 +4.61%, 월간 +21.12% 변동으로 기록되어 시장의 위험 프리미엄 신호가 관측됐다.
- 호르무즈 해협 프로필은 긴장 고조 시 선박 억류 위험을 `Critical`로 표기하지만, 이는 센서 프로필상의 위험 평가이며 실제 억류 발생을 뜻하지 않는다.
- 공개 Telegram 군사 주장은 독립 확인 전까지 행위자의 주장으로만 취급한다.

### 비교 기준: 대만·말라카 해협

- 대만 해협은 해운·반도체 공급망 영향도가 높지만, 이번 자료에서 물리·시장 신호가 홍해·호르무즈와 같은 수준으로 결합됐다는 근거는 확인하지 못했다.
- 말라카 해협은 현재 자료상 `NORMAL` 프로필로 기록되어 있으며, 별도 경보 신호는 확인 필요 상태다.

## 3. 종합 판단

| 구분 | 판단 |
|---|---|
| 위험 신호 | 홍해·호르무즈의 해상안보 및 시장 프리미엄 신호 증가 |
| 신호 괴리 | 공개 주장·시장 반응과 실제 물리적 운항 변화 사이에 추가 확인 필요 |
| 조기경보 후보 | 홍해·바브엘만데브: Warning 검토 후보 / 호르무즈: Warning 검토 후보 |
| 정식 Alert Level | `v_dashboard_current_alerts` 확인 전 `확인 필요` |
| 근거 범위 | GDELT 제한 프로브, 해협 프로필, 시장 프록시, 공개 온라인 신호 |
| 검증 상태 | 교차검증 후보. 완전한 사건 조사나 공급망 중단 확정 아님 |

## 4. 한국 공급망 영향

- 홍해·바브엘만데브 위험이 지속되면 유럽향 컨테이너 운송의 우회와 리드타임 증가가 주요 영향 경로가 된다.
- 호르무즈 긴장이 실제 항행 제한으로 이어질 경우 원유·LNG·석유화학 원료 운송과 한국 에너지 수입 비용에 영향을 줄 수 있다.
- 현재 자료만으로 가격·운임의 원인을 해협 사건 하나로 귀속하지 않는다. 보험료, 항만·AIS, 선사 공지, 공식 발표를 시간축으로 추가 대조해야 한다.

## 5. 확인 필요 사항

1. 미국 병력·항모 전개 보도의 공식 발표 및 독립 언론 원문 확인
2. 홍해·호르무즈 실제 선박 통항량, AIS 공백, 항만 지연의 시간대별 비교
3. FRO·ZIM 변동이 해상 위험과 직접 연결되는지 다른 시장 요인과 분리
4. 공개 Telegram 주장의 독립 출처 교차 확인
5. `v_dashboard_current_alerts`, `v_alert_evidence_trace`, `v_alert_validation_summary`에 근거·사람 검수 결과가 적재됐는지 확인

## 결론

현재 가장 뚜렷한 조기경보 후보는 홍해·바브엘만데브와 호르무즈 해협이다. 여러 계통의 신호가 같은 방향을 가리키지만, 수집 범위가 제한되고 일부 근거가 공개 주장·시장 프록시이므로 정식 경보를 자동 확정하지 않는다. 추가 근거가 확인될 때까지 운영 화면에서는 `Warning 검토 후보`와 `확인 필요`를 구분해 표시한다.
