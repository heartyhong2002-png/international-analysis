# 보고서 해석 주의

이 폴더의 보고서는 대시보드를 뒷받침하는 시점별 분석 산출물이다. 미래 사건 예측의 정확도, 전문가 검증, 사실 확정을 의미하지 않는다.

- 경보·전망·위험도는 당시 수집된 신호에 대한 탐색적 해석이며, 근거 URL과 사람 검수가 없는 단정으로 사용하지 않는다.
- 모델 간 일치는 사실성 또는 객관성의 증거가 아니다. 사람 검수와 근거 품질 확인이 완료되기 전에는 `검토 필요`로 해석한다.
- 과거의 "100% 정확도", "환각 0%", "완벽 검증" 표현이 담긴 산출물은 `docs/archive/pre_pivot_validation_outputs/`에 이력으로 보관하며, 현재의 품질 주장에 사용하지 않는다.
- 현재 검증 절차와 오류 기록 기준은 [`docs/current/VALIDATION_PLAN.md`](../docs/current/VALIDATION_PLAN.md)를 따른다.
