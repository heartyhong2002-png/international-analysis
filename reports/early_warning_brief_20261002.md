# 공급망·지정학 리스크 조기경보 간이 보고서

**기준일:** 2026-10-02  
**문서 상태:** 검토용 요약본 · 자동 Alert Level 확정 문서 아님

## 1. 목적

이 문서는 국제정세 사건의 발생을 예측하는 보고서가 아니다. 수집된 공급망·지정학 신호를 출처별로 확인하고, 추가 검토가 필요한 위험 신호와 근거 상태를 요약한다.

## 2. 현재 관측 체계

- 직접 센서: 해협·항만 통항 및 지연, 해상 운임·시장 프록시, 에너지 가격, 전쟁위험보험료
- 교차검증 센서: GDELT Cloud 사건, 정부·군 공식 발표, 독립·현지 언론, 공개 Telegram, 공개 포럼
- 보조 프록시: Google Trends, 공개 로컬 여론, 기존 논조·신호 괴리 자료

단일 출처나 단일 센서만으로 경보 단계를 상향하지 않는다. GDELT의 `complete=false` 결과는 부분 수집으로 취급하며 전체 사건 목록으로 해석하지 않는다.

## 3. 검토 대상 신호

현재 작업 산출물에는 GDELT 사건 후보, 해협·시장 센서, 로컬 여론 및 Telegram 공개 채널의 교차검증 결과가 포함되어 있다. 교차검증 결과는 `CROSS_VERIFIED`, `PARTIALLY_CONFIRMED`, `UNVERIFIED` 상태로 구분하고, 각 항목에 사건 시각·출처 URL·관측 시각·결합 채널을 남긴다.

이 문서에서는 해당 후보들을 근거로 사건 발생이나 공급망 중단을 확정하지 않는다. 각 후보는 공식 발표, 물리·시장 지표, 독립·현지 출처와의 시간·지리·주제 일치 여부를 추가 확인해야 한다.

## 4. Alert Level 및 검증 상태

정식 Alert Level은 `v_dashboard_current_alerts`에서만 읽는다. 이 뷰에 기록된 `alert_events`와 연결된 근거·점수·신호 괴리·사람 검수 상태가 없으면 `확인 필요`로 표시한다.

현재 이 간이 보고서는 별도 산식으로 Warning이나 Critical을 계산하지 않는다.

| 항목 | 상태 |
|---|---|
| 정식 Alert Level | `v_dashboard_current_alerts` 확인 필요 |
| 근거 추적 | `v_alert_evidence_trace` 연결 필요 |
| 신호 괴리 | `v_signal_gap_trend` 확인 필요 |
| 사람 검수·백테스트 | `v_alert_validation_summary` 확인 필요 |
| 오탐·미탐 판정 | 실제 검토 결과 입력 전까지 보류 |

## 5. 다음 확인 사항

1. 교차검증 후보별 원문 출처와 관측 시각을 대조한다.
2. `CROSS_VERIFIED` 상태가 실제로 서로 독립적인 출처 계통을 의미하는지 확인한다.
3. `v_dashboard_current_alerts`의 Alert Level과 연결된 근거 문장을 확인한다.
4. 사람 표본 검수 및 과거 사례 백테스트 결과를 기록한다.
5. 근거가 부족하거나 출처가 중복된 항목은 경보를 올리지 않고 `확인 필요`로 유지한다.

## 결론

현재 산출물은 공급망·지정학 위험 신호를 수집하고 교차검증하기 위한 관측 기반이다. 사건 발생을 단정하지 않으며, 정식 경보 단계는 공식 대시보드 뷰와 근거·검증 상태가 연결된 경우에만 표시한다.
