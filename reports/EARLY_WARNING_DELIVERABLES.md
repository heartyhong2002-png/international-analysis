# 조기경보 대시보드·제출 산출물 명세

## 1. 최종 사용자 화면

최종 결과물은 `output/dashboard/index.html`이다. 이 화면은 미래 사건을 단정하거나 맞힐 가능성을 표시하는 화면이 아니라, 이슈별 관측 신호를 사람이 검토할 수 있게 정리하는 조기경보 화면이다.

각 이슈 카드에는 아래 정보를 같은 화면에서 제공한다.

| 항목 | 화면 표현 원칙 |
|---|---|
| Alert Level | `Normal`, `Watch`, `Warning`, 또는 근거 부족 시 `확인 필요` |
| 위험 신호 | 관측된 변화의 짧은 서술. 사건 발생을 단정하지 않음 |
| 신호 괴리 | 공식 발표와 독립·현지·대중·시장 신호 간 차이의 서술 |
| 근거 출처 | 원문 링크, 출처 유형, 수집 시각, 추출 근거 문장 |
| 근거 범위 | 어떤 출처 유형이 포함됐는지와 근거 수량/충분도 |
| 검증 상태 | 사람 검수, 백테스트, 보류·확인 필요 여부 |

수집량, 논조 분포, 정부 발표 비중은 **보조 관측 지표**로만 제시한다. 이 지표만으로 Alert Level을 유추하거나 확정하지 않는다.

## 2. 제출용 증거 산출물

`reports/`에는 대시보드를 뒷받침하는 자료를 둔다. 각 문서는 제목·요약·결론에 다음을 명시한다.

- 현재 Alert Level과 판정 시각
- 위험 신호와 반대·불확실 신호
- 근거 목록(원문, 출처 유형, 수집 시각, 인용 또는 추출 근거)
- 근거 범위와 신호 괴리
- 검증 상태: 사람 검수 결과, 백테스트 결과, 오탐·미탐 후보
- 한계와 추가 확인 필요 사항

PDF·Word·Markdown 이슈 보고서는 “예측”, “발생 가능성”, “확정적 전망” 대신 “조기경보”, “위험 신호”, “근거”, “확인 필요”, “경보 단계”를 사용한다. 장기 정세 배경은 보조 맥락으로 유지할 수 있으나, Alert Level의 근거인 것처럼 표현하지 않는다.

## 3. 대시보드·보고서 데이터 계약 요구사항

대시보드 담당은 Alert Level 산식, LLM 판단 규칙, DB 테이블을 임의로 만들지 않는다. 분석·DB 담당은 이슈별 최신 스냅샷과 이를 읽을 SQL을 제공해야 한다. 대시보드는 `EARLY_WARNING_SNAPSHOT_QUERY` 환경 변수로 전달된 승인 SQL만 실행한다. 아래는 그 결과에 필요한 필드 계약이며, 뷰·테이블 이름과 실제 SQL은 DB 담당이 정한다.

| 필드 | 필요 이유 |
|---|---|
| `issue` | 대시보드·보고서 이슈 식별자 |
| `alert_level` | 확정된 경보 단계 (`Normal` / `Watch` / `Warning`) |
| `risk_signal_summary` | 사용자에게 보일 위험 신호 요약 |
| `signal_gap_summary` | 출처 간 괴리 설명 |
| `evidence_coverage` | 근거 범위·충분도 표현 |
| `evidence_count` | 근거 수량 표시 |
| `validation_status` | 검수·백테스트·보류 상태 |
| `human_review_status` | 사람 확인 여부 |
| `assessed_at` | 해당 판단의 기준 시각 |

추가로, 이슈별 근거 목록에는 `issue`, `source_type`, `source_name`, `source_url`, `published_at`, `collected_at`, `evidence_quote`, `review_status`가 필요하다. 실제 테이블 또는 뷰 이름은 DB 담당이 정하되, 위 의미를 제공해야 한다.

## 4. 경보 단계·검증 규칙의 소유권

- Alert Level 승격·하향 규칙과 Risk Signal Score 산식: 분석/LLM 담당
- 입력 데이터의 적재 방식과 뷰 구현: DB 담당
- 사람 검수 표본 선정 및 판정 기준: 검증 담당
- 화면 문구, 근거 연결, ‘확인 필요’ 안전표시, 제출 문서 구성: 대시보드·보고서 담당

스냅샷이 없거나 필수 근거·검증 정보가 빠진 경우, 대시보드와 보고서는 Alert Level을 추정하지 않고 `확인 필요`로 표시한다.
